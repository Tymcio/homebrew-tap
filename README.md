# Homebrew tap for NotchFlow

```bash
brew install --cask tymcio/tap/notchflow
```

[NotchFlow](https://notchflow.eu) puts your coding agents (Claude Code, Codex, Cursor), music, files,
calendar and timers in an island at the top of your Mac's screen. Source:
[Tymcio/notchflow](https://github.com/Tymcio/notchflow).

The cask always installs the latest signed and notarized release; the app updates itself with
Sparkle, so `brew upgrade` is not needed.
