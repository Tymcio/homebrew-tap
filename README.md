# Homebrew tap for NotchFlow

```bash
brew tap tymcio/tap
brew trust --cask tymcio/tap/notchflow
brew install --cask notchflow
```

Homebrew 7 asks you to trust casks from third-party taps once (`brew trust`).

[NotchFlow](https://notchflow.eu) puts your coding agents (Claude Code, Codex, Cursor), music, files,
calendar and timers in an island at the top of your Mac's screen. Source:
[Tymcio/notchflow](https://github.com/Tymcio/notchflow).

The cask always installs the latest signed and notarized release, and the app keeps itself up to
date with Sparkle.
